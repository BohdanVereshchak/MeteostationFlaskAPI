# Метеостанція
## Стурктура проєкту

/project
    /static
    /templates
    app.py
<pre lang="md"><code>project/ 
├── static/ 
├── templates/ 
└── app.py</code></pre>

- app.py: Це основний файл додатка, де визначаються маршрути та подання.
- /templates: Це директорія, в якій зберігаються всі HTML-шаблони. Flask автоматично шукає шаблони в папці з ім'ям templates. Приклади шаблонів можуть включати hello.html, index.html, about.html і так далі.
- /static: Ця папка використовується для зберігання статичних файлів, як-от CSS-стилі, JavaScript-скрипти, зображення та інші файли, що не змінюються в процесі роботи програми. Flask автоматично обробляє запити до цих файлів.

## Endpoints
- / - кореневий endpoint, використовується як початкова сторінка
- /api/sensors - для взаємодії з даними про сенсори
- /api/config - для взаємодії з конфігом
